# pehota-plugins

Claude Code plugin marketplace.

```
/plugin marketplace add pehota/claude-plugins
/plugin install dod@pehota-plugins
/plugin install media-writer@pehota-plugins
/plugin install nudges@pehota-plugins
```

| Plugin | What |
|---|---|
| `dod` | Task Definition-of-Done contract, Stop gate, verification |
| `media-writer` | Technical articles and X posts |
| `nudges` | Self-improvement nudges on typed prompts |
